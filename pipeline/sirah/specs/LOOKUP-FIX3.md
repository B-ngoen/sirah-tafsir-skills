# lookup.py perbaikan 3 — paging & daftar isi segmen (untuk Mode MATERI/LENGKAP)
Tambahkan opsi pada `event`, `person`, `year` (semua yang menampilkan segmen):
1. `--toc` : jangan cetak teks; cetak daftar isi per segmen: seg_id, sumber, hal.web, jumlah paragraf, lalu daftar sub-heading di dalam segmen — paragraf yang (setelah strip tasykil) ≤ 70 karakter DAN (diawali `(` dan diakhiri `)`/`:` ATAU diawali kata غزوة|سرية|ذكر|حديث|أمر|قصة|خبر|باب|فصل|شعر|ما نزل|سنة ATAU diapit `[ ]`) → cetak `para_idx  judul`. Tujuan: agent membaca segmen panjang bab demi bab.
2. `--seg <seg_id>` : batasi output ke satu segmen (event_segments/year_segments/person_entries.entry_id sesuai konteks).
3. `--paras A-B` : cetak hanya paragraf indeks A..B (0-based, relatif dari awal segmen; gabungan lintas halaman sesuai urutan) dari segmen terpilih; wajib bersama `--seg`. Tanpa `--max-chars` (penuh untuk rentang itu). Tampilkan sitasi halaman untuk paragraf pertama dan terakhir rentang (juz/hal/URL berubah bila melewati batas halaman — cetak `— halaman: juz X hal Y (URL)` tiap kali halaman berganti).
4. `--format json` mendukung semuanya (toc: array {seg_id, source, from_page, to_page, n_paras, headings:[{para_idx,title}]}; paras: array {para_idx, web_page, printed_juz, printed_page, url, text}).
5. Help & docstring diperbarui. Uji: `event ghazwah_badr_kubra -s hisyam_saqqa --toc` (≥15 sub-heading), `event ghazwah_badr_kubra --seg 21 --paras 0-40`, `person 4835 --toc`, `year 6 --toc`, `--seg` tanpa `--paras` (teks segmen penuh), kombinasi salah → exit 2 rapi; regresi semua uji lama (FIX1+FIX2) tetap lulus.
