# Gemini — panduan

Panduan lengkap (NotebookLM → Gem) ada di [docs/gemini.md](../docs/gemini.md).

Isi folder ini:
- `instructions-sirah.md`, `instructions-tafsir.md` — teks petunjuk (juga disertakan di dalam zip rilis sebagai `PETUNJUK-tempel.txt`).
- `export_knowledge.py` — membuat paket teks dari basis data (`KNOWLEDGE_MAX_WORDS` default 450.000 kata, pecah di awal bab).
- `txt_to_pdf.py` — versi PDF (RTL, Amiri) bila diperlukan.
